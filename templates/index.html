          Hybrid EfficientNetV2B3 + ViT Pipeline Architecture

          Based on Sinamenye et al. (2025), "Potato plant disease detection: leveraging hybrid deep learning models", BMC Plant Biology.

          Input Image RGB (224 × 224 × 3)
          CNN Branch (Local)
          EfficientNetV2B3 Pre-trained ImageNet-21k (Frozen)
          ↓
          GAP Flatten Vector Dim: 1536
          ViT Branch (Global)
          ViT-Base (16×16 patch) Pre-trained ImageNet-21k (Frozen)
          ↓
          [CLS] Linear Projection 768 → 512 dimensions
          ↓ Concatenation ↓
          Dual-Path Concatenation Layer 1536 (Local) + 512 (Global) = 2048 Dimensions
          ↓
          Dropout (rate = 0.2) & Classification Head Linear (2048 → 7 Target Disease Classes) + Softmax
          Target Classes 7 Classes
          Augmentation Affine, ColorJitter, Flips
          Optimizer Adam (lr = 1e-4)
          Scheduler ReduceLROnPlateau
